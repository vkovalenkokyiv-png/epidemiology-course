# Епідеміологія

> **Освітній рівень:** Другий (магістерський)  
> **Галузь знань:** I «Охорона здоров'я та соціальне забезпечення»  
> **Спеціальність:** І9 «Громадське здоров’я» (ОП «Організація охорони здоров’я»)  
> **Обсяг дисципліни:** 6 кредитів ЄКТС / 180 годин (Аудиторні: 20 год., Самостійна робота: 160 год.)  
> **Викладач:** асистент кафедри громадського здоров’я Володимир КОВАЛЕНКО 

---

## 🎯 Мета навчальної дисципліни
Формування у здобувачів вищої освіти системних фахових компетентностей щодо використання епідеміологічного методу, аналізу популяційних та клінічних даних, інфекційного контролю та біобезпеки для прийняття обґрунтованих управлінських рішень в сфері охорони здоров’я.

## 📚 Структура курсу та матеріали
Використовуйте навігаційне меню зліва для переходу до відповідних тем лекцій, методичних матеріалів та завдань для самостійної роботи.

## 🔗 Основна нормативно-правова база
- Закон України [«Про систему громадського здоров’я» № 2573-ІХ](https://zakon.rada.gov.ua/laws/show/2573-20#Text).
- Наказ МОЗ України [від 03.08.2021 № 1614 «Про організацію профілактики інфекцій та інфекційного контролю в закладах охорони здоров'я»](https://zakon.rada.gov.ua/laws/show/z1318-21#Text).
- Постанова Кабінету Міністрів України [від 22.04.2026 № 505 щодо епіднагляду та розслідування спалахів](https://zakon.rada.gov.ua/laws/show/505-2026-%D0%BF#Text).
