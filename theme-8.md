# Тема 8. Епідеміологія AMR та адміністрування протимікробних препаратів

## 1. Проблема антимікробної резистентності (AMR)
Антимікробна резистентність є глобальною загрозою громадському здоров'ю. Нераціональне призначення антибактеріальних препаратів призводить до селекції мультирезистентних штамів мікроорганізмів у стаціонарах, що значно підвищує рівень смертності, тривалість лікування та витрати на медичну допомогу.

---

## 2. Програма адміністрування антимікробних препаратів (AMS) та класифікація AWaRe
Для стримування AMR у закладах охорони здоров'я впроваджується **Програма адміністрування антимікробних препаратів (AMS)** як невіддільна частина системи інфекційного контролю[cite: 1].
* **Класифікація ВООЗ AWaRe:** усі антибіотики поділені на три групи для контролю за їх використанням:
  1. **Access (Доступ):** препарати першого та другого вибору для лікування найпоширеніших інфекцій, які мають низький потенціал резистентності.
  2. **Watch (Спостереження):** антибіотики з вищим ризиком розвитку резистентності, їх застосування має бути суворо обмеженим.
  3. **Reserve (Резерв):** препарати «останньої надії» для лікування інфекцій, спричинених мультирезистентними бактеріями (їх призначення вимагає особливого погодження).

---

## 3. Методологія моніторингу споживання (DDD) та периопераційна антибіотикопрофілактика
* **Одиниця вимірювання (DDD, Defined Daily Dose):** стандартизована середня добова доза препарату для його основного застосування у дорослих. Споживання антибіотиків у стаціонарі розраховується за формулою кількості DDD на 100 ліжко-днів.
* **Периопераційна антибіотикопрофілактика (ПАП):** регламентується новими стандартами медичної допомоги (зокрема Наказом МОЗ України **від 23.04.2026 № 540**)[cite: 1] задля запобігання інфекціям області хірургічного втручання шляхом своєчасного введення разової дози антибіотика до розрізу.

## 📝 Завдання для самостійної роботи (16 годин)
- **Опрацювати нормативні акти:** Вивчити додатки до Наказу МОЗ № 1614 щодо AMS, Стандарт за Наказом МОЗ № 540 та міжнародну класифікацію ВООЗ AWaRe[cite: 1].
- **Практичний кейс:** Здійснити аналіз умовних даних аптечного складу лікарні та згрупувати використані за місяць протимікробні препарати за категоріями **AWaRe (Access, Watch, Reserve)** з розрахунком загальних показників[cite: 1].
